# Internationalization

UI strings should go through a thin message catalog so locales can be added later.

## Current state

- Default locale: English (`en`)
- Coach **WAV** clips remain English; localizing speech is a separate pipeline
  (`scripts/generate-audio-clips.ps1`)

## Usage

```ts
import { t } from "../shared/i18n";

t("live.startMonitor"); // → "Start live monitor"
```

Add keys to `src/shared/i18n/en.ts`. Do not hard-code user-visible English in new
UI when a key already exists (or add one).
